# GEMINI.md

This file exists only because Gemini-based tools (including Antigravity)
default to looking for this filename. All real instructions live in
`AGENTS.md` in this repository's root — do not duplicate them here.

Before doing anything else: read `AGENTS.md` in full, then `PROJECT_MAP.md`
and `CONTEXT.md`. Follow the workflow, decision loop, and guardrails defined
in `AGENTS.md` exactly, including the multi-agent handoff protocol in its
"Switching between agents/tools mid-project" section.

If your settings support pointing `context.fileName` directly at `AGENTS.md`,
that is the more robust fix — this file is a fallback in case that isn't
configured.
